# Project Rules & Aesthetic Guidelines

## Non-Negotiable Design Standards
- **No Purple Gradients**: Never use purple gradients, indigo-to-purple blends, or tacky "vibe product" color palettes. Use restrained, professional, high-contrast palettes (slate, deep navy, neutral charcoal, crisp monochrome, or curated enterprise blue).
- **No Pill-Shaped Buttons**: Never use `rounded-full` on buttons. Use standard, disciplined geometric radii (`rounded-md`, `rounded-lg`, or `rounded-xl`).
- **No Fake Reviews or Fake Metrics**: Never display hardcoded mock testimonials, fake customer counters, or artificial vanity metrics. Show real data or clean empty states.
- **No Vague Hero Text**: Hero sections and headers must state specific, accurate, functional capabilities. No buzzword-heavy AI fluff.
- **No Emoji Icons**: Use crisp, accessible SVG or Lucide icons exclusively. Never use emojis as UI icons.
- **No Em Dashes (—)**: Use hyphens (-), colons (:), or clean phrasing. Never use em dashes.
- **No Over-The-Top Scroll Animations or Cursor Effects**: No custom cursor animations, floating orbs, or disorienting scroll-jack animations. Keep UI snappy, accessible, and fast.
- **No AI-Slop Photos or Copy**: Use authentic, purposeful imagery and precise, human-grade copywriting.
- **No "Made with AI" Tags**: Keep the product clean, professional, and unbranded by external AI generators.
