# Aesthetic and Product Quality Standards

Strict rules for all frontend and copy implementation across AutoExam Grading:

1. **No Purple Gradients**: Avoid purple gradients, purple glow blobs, or trendy "AI vibe" gradient texts. Use solid, restrained colors or clean neutral/navy accents.
2. **No Pill-Shaped Buttons**: Buttons must use geometric radii (`rounded-md` or `rounded-lg`). Never use `rounded-full` for action buttons.
3. **No Fake Metrics or Fake Activity**: Avoid fictitious recent activity (e.g. "Admin Sarah uploaded 45 exams") or simulated counters. Display actual system logs or legitimate empty states.
4. **No Vague Hero Text**: Use clear, direct, and utilitarian copy.
5. **No Emojis as UI Icons**: Use SVG icons or Lucide icons instead of unicode emojis.
6. **No Em Dashes (—)**: Replace with standard hyphens (-), colons, or restructure the sentence.
7. **No Over-The-Top Animations or Cursor Effects**: No bouncy orbs, trailing cursors, or excessive scroll transitions.
8. **Pre-Launch Gates**:
   - Custom domain configured
   - Dedicated favicon
   - No "Made with AI" mentions
   - Functional Privacy Policy page (`/privacy`)
   - Functional Terms and Conditions page (`/terms`)
